What This Plugin Does

Metadata governs how search engines, social platforms, and AI crawlers understand your content. Metamanager manages all of it at two layers:

  • Media layer: Lossless compression and bidirectional metadata sync between WordPress fields and embedded file tags. Requires OS daemons.
  • Web layer: SEO titles, descriptions, Open Graph, Schema.org JSON-LD, sitemaps, robots.txt, broken link checker, business profile. Works on any host.

The plugin works without daemons for web/SEO features. Jobs queue but don't execute until daemons are running.

Media Processing

Lossless Compression

JPEG (jpegtran), PNG (optipng), WebP (cwebp), AVIF (avifenc), video remux (ffmpeg). Files are only replaced if the result is smaller. Configurable optimization level 1-7 for PNG/WebP (default 2).

Bidirectional Sync

  • File to WordPress: On upload, ExifTool reads embedded tags and populates empty WordPress fields. Existing values are never overwritten.
  • WordPress to File: After save, the daemon writes WordPress values back into the file.

GPS

GPS coordinates from camera EXIF are imported automatically and stored as _mm_gps_lat, _mm_gps_lon, _mm_gps_alt. Used in Schema.org ImageObject output.

Dashboard

Top-level "Metamanager" menu with job queue, searchable history, cron event tracking, daemon health indicators, and bulk action controls. Auto-refreshes every 5 seconds.

Media Library Columns

  • Compression: Compressed / Partial / Not Compressed / N/A
  • Meta Sync: Embedded / Queued / Not Embedded

Bulk Actions

  • Compress Lossless: Queues compression for selected attachments
  • Inject Site Info: Writes Publisher and Website into IPTC/XMP

Write-back Verification

After the daemon writes metadata, it re-reads the file to verify values match. Discrepancies shown on attachment edit screen.

SEO Features

Titles and Descriptions

Per-post/page/term/user title and description with template tokens: %%sitetitle%%, %%post_title%%, %%sep%%, %%author_name%%, %%search_query%%, %%current_year%%, %%category%%, %%term_title%%.

Open Graph and Twitter

og:type, og:title, og:description, og:image (with dimensions/type/alt), og:video, og:audio, article timestamps. Twitter/X cards with twitter:card, twitter:creator from author profile.

Schema.org JSON-LD

Emits a @graph on every page with nodes for WebSite, WebPage, BreadcrumbList, Article, BlogPosting, Person, LocalBusiness, ImageObject, VideoObject, AudioObject, DigitalDocument, Product, Event, Service, HowTo, FAQPage.

Page Templates

mm-about (AboutPage), mm-contact (ContactPage), mm-calendar (Calendar). Auto-generated from business profile and events.

XML Sitemaps

/sitemap.xml (index), /sitemap-post-{type}.xml, /sitemap-tax-{taxonomy}.xml, /sitemap-media.xml, /sitemap-video.xml. Ping Google and Bing on publish.

HTML Sitemap

[mm_sitemap] shortcode with attributes: post_types, taxonomies, depth, exclude, columns, show_date, order_by.

Robots.txt

Dynamic robots.txt with configurable Disallow/Allow, crawl-delay, custom directives. Auto-appends Sitemap directive.

Broken Link Checker

Async checking via WP-Cron. Dashboard with HTTP codes, re-check, ignore, email alerts. Configurable check interval and timeout.

Business Profile

Name, type, address, phone, email, hours, geo, social profiles. Powers LocalBusiness JSON-LD. Gutenberg block, shortcode, widget for contact card. Exports vCard, JSON, CSV, iCal.

Head Cleanup

Remove: generator tag, oEmbed links, shortlink, WLW manifest, RSD link, X-Pingback header, X-Powered-By header, DNS prefetch.

RSS Feed Cleanup

Remove generator, strip comment elements, excerpt-only, custom title, copyright.

AI Discovery

/llms.txt, /llms-full.txt, /.well-known/api-catalog for AI agent discoverability.

Multisite

Network activation creates DB tables and schedules cron on every site. New sites handled via wp_initialize_site hook.

Updating

Updates appear in Dashboard → Updates. After updating, restart daemons: sudo systemctl restart metamanager-compress-daemon metamanager-meta-daemon

Installation

Requirements

  • WordPress 6.2+, PHP 8.0+
  • Daemon package: sudo apt install metamanager

Plugin Install

wp plugin install metamanager --activate

Verify

systemctl status metamanager-compress-daemon
systemctl status metamanager-meta-daemon
